# Music Explorer - A Simple C# .Net App with Windows Forms

The project was developed in .Net 10. See the documentation in the Docs folder for a complete description.
Music Explorer uses a handful of free web services to list the albums for a given recording artist. For each album, it shows the songs and the lyrics. Enjoy!
